## Offline Support

This app uses the [Angular service worker](https://angular.dev/ecosystem/service-workers) (`@angular/service-worker`), generated as part of the production build, to load quickly and work offline.

## Build process

This project uses the [Angular CLI](https://angular.dev/tools/cli) (Angular 20). It requires Node.js `^20.19 || ^22.12 || ^24`.

 - Clone or download the repo
 - `npm install`
 - `npm start` to run the app with the dev server at `http://localhost:4200`, or `npm run build` to produce a production build in `dist/`

The service worker is generated by the Angular CLI (`serviceWorker` in `angular.json` / `ngsw-config.json`) as part of the production build and is disabled in development. To exercise it locally, run `npm run build` and serve the `dist/` output over HTTP (e.g. `npx http-server dist/angular-hnpwa -p 8080`).

## Testing

 - `npm test` — unit tests (Karma + Jasmine, headless Chrome)
 - `npm run e2e` — end-to-end tests ([Playwright](https://playwright.dev); auto-starts the dev server). First run: `npx playwright install chromium`
 - `npm run lint` — ESLint (angular-eslint)
